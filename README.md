# SkateSync AI Frontend

Bu proje, SkateSync AI uygulaması için geliştirilmiş bir React (Vite) frontend uygulamasıdır.

## 🚀 Başlangıç

Projeyi kendi bilgisayarınızda çalıştırmak için aşağıdaki adımları takip edebilirsiniz.

### Ön Koşullar

Bilgisayarınızda **Node.js**'in yüklü olduğundan emin olun. Yüklü değilse [buradan indirebilirsiniz](https://nodejs.org/).

### Kurulum ve Çalıştırma

1. **Bağımlılıkları Yükleyin**

   Proje dizininde bir terminal veya komut satırı açın ve gerekli kütüphaneleri yüklemek için aşağıdaki komutu çalıştırın:

   ```bash
   npm install
   ```

2. **Projeyi Başlatın**

   Kurulum tamamlandıktan sonra geliştirme sunucusunu ayağa kaldırmak için aşağıdaki komutu girin:

   ```bash
   npm run dev
   ```

3. **Tarayıcıda Görüntüleyin**

   Terminalde beliren adrese (genellikle `http://localhost:5173/`) tarayıcınızdan giderek uygulamayı kullanmaya başlayabilirsiniz.

---

## 🛠️ Diğer Kullanışlı Komutlar

- **Uygulamayı Canlı İçin Derleme (Build):**
  ```bash
  npm run build
  ```

- **Derlenmiş Hali Önizleme:**
  ```bash
  npm run preview
  ```
